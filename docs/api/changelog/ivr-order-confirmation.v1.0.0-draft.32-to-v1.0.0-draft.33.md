# API Changelog 1.0.0-draft.32 vs. 1.0.0-draft.33


## API Changes

### GET /audit-evidence
-  the response property `rows/items/after_state_json` became not nullable for the status `200`
-  the response property `rows/items/before_state_json` became not nullable for the status `200`
-  the response property `rows/items/reason` became not nullable for the status `200`
