IVR Order Confirmation — Internal/Admin API (Target V1 Draft) (1.0.0)

Download OpenAPI specification:

License: LicenseRef-Proprietary

Target V1 draft for the standalone .NET IVR service. Not a public API. The Sales Platform owns eligibility, revalidation, and order-state transitions. Supports GOLDEN_HOUR+ONLINE and TWENTY_FOUR_SEVEN+COD. External Sales callback is specified separately in order-core-ivr-callback.target-v1.yaml.
